# スポット周辺検索アプリ — 仕様書

## 概要

シードデータとして提供されたスポット（199件）を地図上に表示し、ユーザーが地図を操作しながら周辺のスポットを検索・閲覧できる Web アプリケーション。

## 画面構成

画面は3つのエリアで構成される。

```
┌──────────────────────────────────────────────────────────┐
│ ヘッダー: 📍 地図中心の住所                                  │
├───────────────────────────────────┬────────────────────────┤
│                                   │ 周辺の観光スポット（N件）  │
│          地図エリア                │                        │
│                                   │ スポット一覧（リスト）    │
│   [半径スライダー: N km]           │                        │
│                                   │                        │
└───────────────────────────────────┴────────────────────────┘
```

- **ヘッダー**: 現在の地図中心の住所を常に表示する
- **地図エリア**: 地図・マーカー・検索範囲の円・半径スライダーを表示する
- **スポット一覧**: 検索範囲内のスポットを近い順にリスト表示する

## 機能仕様

### F1. スポットの地図表示

地図上にスポットをマーカーで表示する。

- 初期表示は東京駅周辺（lat: 35.6812, lng: 139.7671）、ズームレベル14
- マーカーをクリックするとポップアップが開き、スポット名・カテゴリ・住所・中心からの距離を表示する

### F2. 半径検索

指定した中心地点から半径 N km 以内のスポットのみを抽出する。

- 地図の中心が検索の中心地点になる。ユーザーが地図をドラッグすると検索中心が追従する
- 検索範囲は地図上に青い半透明の円として描画され、範囲が視覚的にわかる
- 検索半径はスライダーで 0.5km〜20km の範囲で 0.5km 刻みで変更できる。初期値は 3km
- 結果は中心からの距離が近い順に並ぶ

### F3. スポット一覧（リスト）

検索結果を画面右側のリストに表示する。地図と双方向に連動する。

- 各行にスポット名・カテゴリ（バッジ表示）・住所・中心からの距離を表示する
- 距離は 1km 未満は「○○m」、1km 以上は「○.○km」形式で表示する
- リストのスポットをクリックすると、地図がそのスポットの位置にアニメーション移動（flyTo）する。選択中のスポットは背景色で強調する
- 件数はリスト上部に表示する。検索中は「検索中…」、完了後は「N件」を表示する
- 0件の場合は「この範囲にスポットが見つかりませんでした。半径を広げるか、地図を移動してみてください。」と案内する
- APIエラー時はエラーメッセージを表示する

### F4. 地図中心の住所表示

地図を動かしている間、ヘッダーに現在の地図中心の住所をリアルタイムに表示する。

- 住所は逆ジオコーディング（座標→住所変換）で取得する
- 取得中は「住所を取得中…」を表示する
- 住所は都道府県・市区町村・町域・地区を連結した日本語表記で表示する
- API呼び出しのコスト削減として以下を実装する:
  - フロントエンド側で地図移動を 400ms の debounce で間引き、ドラッグ中は API を呼ばない
  - バックエンド側で座標を小数第3位に丸め（約100m単位）、丸めた座標をキーとしてキャッシュする。わずかな移動では同じキャッシュから返す

### F5. データの自動セットアップ

`docker compose up` を実行するだけで、アプリが使える状態になる。

- シードデータ（CSV: 199件のスポット）はアプリ起動時にデータベースへ自動インポートされる
- 再起動しても二重登録されない（テーブルにデータがあればインポートをスキップする）
- 外部APIキーの設定は不要。地図タイルと逆ジオコーディングはいずれもキー不要のサービスを採用した

## 操作フロー

### 周辺のスポットを探す

1. ブラウザで http://localhost:3000 を開く
2. 地図が表示され、初期位置（東京駅周辺）のスポットがマーカーとリストに表示される
3. 地図をドラッグして見たいエリアに移動する → マーカーとリストが自動更新される
4. 必要に応じて左下のスライダーで検索半径を調整する

### スポットの詳細を見る

1. リストでスポット名をクリックする → 地図がそのスポットに移動する
2. マーカーをクリックする → ポップアップにスポット名・カテゴリ・住所・距離が表示される

### 現在地の把握

- ヘッダーの 📍 表示で、今地図のどのあたりを見ているかを常に把握できる
